## Định nghĩa

**Cây Fenwick (Binary Indexed Tree)** làm được đúng hai việc nhưng cực nhanh:
**cập nhật điểm** và **lấy tổng tiền tố** — cả hai O(log n), với mã nguồn ngắn
hơn cây phân đoạn nhiều.

Trái tim của cấu trúc này là phép `i & (-i)`: **bit thấp nhất đang bật của i**.
Nút `i` của cây quản lý một đoạn dài đúng `i & (-i)` kết thúc tại `i`:

| i | nhị phân | i & (-i) | quản lý |
| - | -------- | -------- | ------- |
| 1 | 0001 | 1 | a[1] |
| 4 | 0100 | 4 | a[1..4] |
| 6 | 0110 | 2 | a[5..6] |
| 8 | 1000 | 8 | a[1..8] |

## Input mẫu

| Input | Ý nghĩa |
| ----- | ------- |
| Mảng `[5, 2, 9, -1, 4, 7, 1, 8]` | 8 phần tử, đánh số 1..8 |
| Truy vấn 1: tổng `[1..5]` | Đi theo các nút 4 → 5 |
| Cập nhật: `a[2] += 6` | Chỉ các nút "phủ" a[2] được tăng |

**Output mong đợi:**

```text
Tổng [1..5] = 5 + 2 + 9 + (-1) + 4 = 19
Sau cập nhật a[2]: 8 → tổng [1..8] = 35 + 6 = 41
```

## Ý tưởng

```text
tổng tiền tố [1..i]:
    while i > 0: s += tree[i]; i -= i & (-i)   // bỏ bit thấp nhất
cập nhật a[i] += x:
    while i ≤ n: tree[i] += x; i += i & (-i)   // bò lên các nút phủ nó
```

Xem minh họa: bước đầu dựng cây từ mảng (mỗi phần tử dội giá trị lên các nút
phủ nó), sau đó là 2 truy vấn tổng theo chuỗi nút `4 → 5`, cuối cùng cập nhật
điểm — chú ý đúng các nút 2, 4, 8 được cộng:

<ArrayVisualizer algorithm="fenwick" height={230} />

Ba điểm đáng nhớ:

1. **1-indexed bắt buộc**: mảng hiệu `i & (-i)` của i = 0 là 0 → lặp vô hạn.
2. Cây Fenwick **mở rộng lên 2D** (`fenwick-2d`) cho truy vấn bảng — cây phân
   đoạn 2D nặng hơn nhiều.
3. Cần **min/max đoạn** hoặc truy vấn đoạn bất kỳ → dùng cây phân đoạn; chỉ cần
   tổng + cập nhật điểm → Fenwick gọn và nhanh hơn.

## Kết quả (Output)

Trực quan giải thích kết quả: tổng `[1..5]` = tree[4] + tree[5] = 15 + 4 = 19 —
vì tree[4] gộp sẵn a[1..4] (5+2+9-1 = 15), tree[5] chỉ là a[5]. Chuỗi nút
`4 → 5` chính là các bước "bỏ bit thấp nhất" của 5 = 0b101 → 0b100 → 0b000.

Sau cập nhật a[2] += 6: các nút có bit 2 bật (2 = 0b0010, 4 = 0b0100, 8 = 0b1000
— tức mọi i mà đoạn của nó chứa a[2]) được +6 ⇒ tổng mới 19 + 6 + (tổng phần
còn lại) đúng bằng 41.

## Code mẫu

```cpp
#include <bits/stdc++.h>
using namespace std;

int n;
vector<long long> bit_;

void update(int i, long long x) {            // a[i] += x (1-indexed)
    for (; i <= n; i += i & (-i)) bit_[i] += x;
}

long long prefix(int i) {                    // tổng [1..i]
    long long s = 0;
    for (; i > 0; i -= i & (-i)) s += bit_[i];
    return s;
}

long long rangeSum(int l, int r) { return prefix(r) - prefix(l - 1); }

int main() {
    n = 8;
    vector<long long> a = {0, 5, 2, 9, -1, 4, 7, 1, 8}; // a[0] bỏ
    bit_.assign(n + 1, 0);
    for (int i = 1; i <= n; i++) update(i, a[i]);
    cout << rangeSum(1, 5) << '\n';   // 19
    update(2, 6);
    cout << rangeSum(1, 8) << '\n';   // 41
    return 0;
}
```

```python
n = 8
a = [5, 2, 9, -1, 4, 7, 1, 8]
bit = [0] * (n + 1)

def update(i, x):
    while i <= n:
        bit[i] += x
        i += i & (-i)

def prefix(i):
    s = 0
    while i > 0:
        s += bit[i]
        i -= i & (-i)
    return s

for i, x in enumerate(a, 1):
    update(i, x)
print(prefix(5) - prefix(0))   # 19
```
