## Định nghĩa

Sắp xếp O(n log n) là "mức thần tốc" thực tế: n = 10⁶ chỉ cần khoảng 2·10⁷ thao
tác so sánh thay vì 10¹² của sắp xếp nổi bọt. Hai thuật toán kinh điển:

- **Quick Sort**: chọn pivot, phân hoạch dãy thành "nhỏ hơn" và "lớn hơn" rồi
  đệ quy hai phía.
- **Merge Sort**: chia đôi đến 1 phần tử, rồi **trộn** các cặp nửa đã sắp.

C++ có sẵn `std::sort` (Introsort — hybrid quick/heap/insertion) nên thường
không phải tự viết; nhưng phải **hiểu** hai ý tưởng này: phân hoạch của Quick
Sort dùng lại trong chọn phần tử thứ k (Quickselect), trộn của Merge Sort dùng
trong đếm cặp nghịch thế.

## Input mẫu

| Input | Ý nghĩa |
| ----- | ------- |
| Mảng `[35, 12, 68, 4, 90, 21, 55, 7]` | Sắp tăng dần bằng Quick Sort / Merge Sort |

**Output mong đợi:**

```text
4 7 12 21 35 55 68 90
```

## Ý tưởng

**Merge Sort**:

```text
sort(lo, hi):
    nếu đoạn ≤ 1 phần tử: dừng
    mid = (lo + hi) / 2
    sort(lo, mid); sort(mid+1, hi)   // hai nửa đã sắp
    trộn hai nửa: so phần tử đầu mỗi nửa, lấy nhỏ hơn vào mảng tạm
```

Ba chi tiết đáng nhớ:

1. **Quick Sort xấu nhất O(n²)** khi pivot luôn là min/max (dãy đã sắp + pivot
   cuối). Khắc phục: chọn pivot ngẫu nhiên hoặc giữa đoạn.
2. **Merge Sort ổn định (stable)**: hai phần tử bằng nhau giữ thứ tự gốc — quan
   trọng khi sắp theo nhiều tiêu chí chồng nhau.
3. **Trộn trực tiếp trên mảng**: đếm cặp nghịch thế bằng cách cộng thêm
   `mid - i + 1` mỗi khi trộn lấy phần tử bên phải trước phần tử trái chưa lấy.

## Độ phức tạp

| Thuật toán | Tốt nhất | Trung bình | Xấu nhất | Bộ nhớ | Ổn định |
| ---------- | -------- | ---------- | -------- | ------ | ------- |
| Quick Sort | O(n log n) | O(n log n) | O(n²) | O(log n) | Không |
| Merge Sort | O(n log n) | O(n log n) | O(n log n) | O(n) | Có |

## Kết quả (Output)

Cả hai đều in ra `4 7 12 21 35 55 68 90` nhưng con đường khác nhau — Quick Sort
"chốt" từng pivot về vị trí cuối cùng của nó (nhìn các ô xanh nhạt chốt dần từ
trái), còn Merge Sort "trộn" các đoạn nhỏ thành đoạn lớn dần (nhìn đoạn xanh
là đoạn đã có thứ tự). 8 phần tử: quick sort ~14 phép so sánh, merge sort đúng
ceil(n log n) ≈ 16 — với n = 10⁶ là ~2·10⁷ so sánh, hoàn thành trong 0,2s,
trong khi nổi bọt n²/2 = 5·10¹¹ là bất khả thi.

## Code mẫu

```cpp
// Merge Sort — đếm luôn cặp nghịch thế (số cặp i<j mà a[i] > a[j])
long long mergeCount(vector<int>& a, int lo, int hi) {
    if (hi - lo <= 1) return 0;
    int mid = (lo + hi) / 2;
    long long cnt = mergeCount(a, lo, mid) + mergeCount(a, mid, hi);
    vector<int> tmp;
    int i = lo, j = mid;
    while (i < mid || j < hi) {
        if (i == mid || (j < hi && a[j] < a[i])) {
            cnt += mid - i;          // mọi phần tử trái còn lại > a[j]
            tmp.push_back(a[j++]);
        } else tmp.push_back(a[i++]);
    }
    copy(tmp.begin(), tmp.end(), a.begin() + lo);
    return cnt;
}
```

```python
def merge_sort(a):
    if len(a) <= 1: return a
    m = len(a) // 2
    L, R = merge_sort(a[:m]), merge_sort(a[m:])
    out, i, j = [], 0, 0
    while i < len(L) and j < len(R):
        if L[i] <= R[j]: out.append(L[i]); i += 1
        else: out.append(R[j]); j += 1
    return out + L[i:] + R[j:]
```
