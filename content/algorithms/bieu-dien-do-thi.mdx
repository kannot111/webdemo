## Định nghĩa

Đồ thị G = (V, E) có **n đỉnh, m cạnh**. Ba cách lưu phổ biến:

| Cách lưu | Bộ nhớ | Kiểm tra (u,v) có cạnh? | Duyệt kề của u | Hợp với |
| -------- | ------ | ----------------------- | -------------- | ------- |
| **Ma trận kề** `a[u][v]` | O(n²) | O(1) | O(n) | n ≤ 3000, đồ thị dày |
| **Danh sách kề** `adj[u]` | O(n + m) | O(deg u) | O(deg u) | Mọi đồ thị — **mặc định** |
| **Danh sách cạnh** | O(m) | O(m) | O(m) | Kruskal, DSU, ngoại tuyến |

## Input mẫu

| Input | Ý nghĩa |
| ----- | ------- |
| `n = 6, m = 9`, cạnh (0,1) (0,2) (1,2) (1,3) (2,3) (2,4) (3,4) (3,5) (4,5) | Đồ thị vô hướng 6 đỉnh |

**Output mong đợi:**

```text
Ma trận kề đối xứng 6×6, 18 ô = 1
Danh sách kề: adj[0] = {1, 2}, adj[2] = {0, 1, 3, 4}, ...
```

## Ý tưởng

Cùng một đồ thị, ba dạng biểu diễn — visualizer vẽ đúng đồ thị mẫu này cho mọi
bài đồ thị khác của site:

<GraphVisualizer algorithm="bfs" height={280} />

Chuyển từ danh sách cạnh sang ma trận kề:

```text
for mỗi cạnh (u, v):
    a[u][v] = a[v][u] = 1        // vô hướng
    // a[u][v] = w nếu có trọng số
```

Ba điểm đáng nhớ:

1. **Đồ thị có hướng**: chỉ set `a[u][v]` một chiều — đừng vô tình thêm cả
   chiều ngược.
2. **Trọng số âm / đa cạnh / khuyên**: ma trận kề khó biểu diễn đa cạnh — dùng
   danh sách kề với `{đỉnh, trọng số, chỉ số cạnh}`.
3. **Đồ thị trên lưới** (mê cung): n·m ô, mỗi ô là đỉnh — kề là 4 ô lân cận,
   không cần danh sách kề tường minh.

## Kết quả (Output)

Với đồ thị mẫu: bậc của đỉnh 2 = 4 (kề 0, 1, 3, 4) là lớn nhất — nhìn hình thấy
ngay đỉnh giữa có nhiều cạnh nhất. Ma trận kề đối xứng (vô hướng); tổng số ô
= 1 của ma trận = 2m = 18. Từ biểu diễn này, mọi phép duyệt BFS/DFS ở bài sau
đều chạy với chi phí O(n + m) — không phụ thuộc cách lưu.

## Code mẫu

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n = 6, m = 9;
    // 1) Ma trận kề — n nhỏ
    vector<vector<int>> a(n, vector<int>(n, 0));
    // 2) Danh sách kề — mặc định
    vector<vector<int>> adj(n);
    // 3) Danh sách cạnh
    vector<pair<int,int>> edges;
    for (auto [u, v] : vector<pair<int,int>>{{0,1},{0,2},{1,2},{1,3},{2,3},{2,4},{3,4},{3,5},{4,5}}) {
        a[u][v] = a[v][u] = 1;
        adj[u].push_back(v); adj[v].push_back(u);
        edges.push_back({u, v});
    }
    // Bậc của mỗi đỉnh từ danh sách kề
    for (int u = 0; u < n; u++) cout << adj[u].size() << ' ';
    cout << '\n';   // 2 3 4 4 3 2
    return 0;
}
```

```python
n, m = 6, 9
adj = [[] for _ in range(n)]
for u, v in [(0,1),(0,2),(1,2),(1,3),(2,3),(2,4),(3,4),(3,5),(4,5)]:
    adj[u].append(v)
    adj[v].append(u)
print([len(adj[u]) for u in range(n)])   # [2, 3, 4, 4, 3, 2]
```
